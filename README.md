# AgentenIndex Unternehmenscheck

Statischer MVP für `check.agentenindex.de`.

## Funktionen
- Prozessklassifikation: Automation / Copilot / Hybrid / Agent / Multi-Agent prüfen
- Agent Opportunity
- Implementation Readiness
- Control & Risk
- Autonomiestufe 0–5
- Hard Gates
- Business-Case-Szenarien
- 30-Tage-Pilotplan
- Matching mit dem AgentenIndex-Datensatz
- lokale Verarbeitung ausschließlich im Arbeitsspeicher des Browsers
- keine persistente Browser-Speicherung (keine eigenen Cookies, kein Local Storage, kein Session Storage)
- Print/PDF über Browser

## Hosting
GitHub Pages, Custom Domain `check.agentenindex.de`. Die Datei `CNAME` ist bereits enthalten.

## Wichtig
Der Check ist eine strukturierte Vorprüfung und keine Rechts-, Datenschutz-, Sicherheits- oder Investitionsberatung.
