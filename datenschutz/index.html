Datenschutz beim Check

Lokale Verarbeitung der Check-Eingaben

Diese Seite ergänzt die allgemeine Datenschutzerklärung von AgentenIndex um die Funktionsweise des Unternehmenschecks.

Keine Übertragung der Check-Inhalte an eine KI-API

Die im Fragebogen eingegebenen Prozessinformationen werden in Version 1 des Unternehmenschecks durch JavaScript direkt im Browser ausgewertet. Die Anwendung sendet diese Eingaben nicht an OpenAI, Anthropic, Google oder einen anderen externen KI-Dienst.

Keine dauerhafte Speicherung im Browser

Die Formularwerte und das berechnete Ergebnis werden nur im Arbeitsspeicher der geöffneten Browserseite verarbeitet. Der Check verwendet hierfür weder Local Storage noch Session Storage noch eigene Cookies. Beim Neuladen oder Schließen der Seite gehen die Eingaben und das Ergebnis verloren. Die Anwendung speichert diese Inhalte nicht in einer AgentenIndex-Datenbank.

Hosting

Der Unternehmenscheck wird als statische Website über GitHub Pages ausgeliefert. Beim Abruf der Website können technisch notwendige Verbindungsdaten beim Hostinganbieter anfallen. Weitere Angaben zum Betreiber und zur allgemeinen Website finden Sie auf AgentenIndex.

Keine vertraulichen Daten eingeben

Der MVP ist für eine Prozessbeschreibung und strukturierte Angaben gedacht. Geben Sie keine Passwörter, API-Schlüssel, personenbezogene Kundendaten, Gesundheitsdaten oder sonstige vertrauliche Geheimnisse in Freitextfelder ein.
